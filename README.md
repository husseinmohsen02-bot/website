# ☕ حَبّة بُن (Habbet Bonn)

موقع لبيع البن التركي أونلاين: العميل يختار المنتجات ويضيفها للسلة، يكتب بيانات التوصيل، والطلب يتسجل عندك في لوحة إدارة تقدر تصدّر منها ملف Excel لشركة الشحن. والعميل بيوصله تأكيد الطلب على واتساب.

## المميزات
- صفحة منتجات عربي (RTL) وبتشتغل كويس على الموبايل
- سلة مشتريات بتفضل محفوظة حتى لو العميل قفل الصفحة
- فورم بيانات التوصيل (الاسم، الموبايل، المحافظة، المدينة، العنوان، ملاحظات) مع التحقق من رقم الموبايل المصري
- الأسعار ومصاريف الشحن بتتحسب على السيرفر، فمحدش يقدر يغيّر السعر من المتصفح
- شحن مجاني اختياري فوق مبلغ معين
- **تأكيد واتساب:**
  - **تلقائي** عبر WhatsApp Cloud API لو ضفت مفاتيح Meta (شوف تحت)
  - **أو** زرار للعميل يبعت تفاصيل الأوردر جاهزة على واتساب المتجر (بيشتغل من غير أي إعداد)
- **لوحة إدارة** على `/admin` بباسورد:
  - كل الطلبات وإحصائيات سريعة
  - تغيير حالة الطلب (جديد ← مؤكَّد ← اتشحن ← اتسلّم / ملغي) وكتابة رقم البوليصة
  - زرار تكلّم بيه العميل على واتساب
  - **تصدير CSV يفتح في Excel** فيه كل اللي شركة الشحن محتاجاه (الاسم، الموبايل، المحافظة، العنوان، المنتجات، المبلغ المطلوب تحصيله)

## التشغيل
محتاج بس Node.js نسخة 18 أو أحدث، ومفيش أي مكتبات لازم تنزّلها.

```bash
cp .env.example .env    # وعدّل القيم اللي جواه
npm start
```
- المتجر: http://localhost:3000
- لوحة الإدارة: http://localhost:3000/admin

## تعديل المنتجات
عدّل ملف `data/products.json`: الاسم، الوزن، السعر، الوصف، والتاج (مثلاً "الأكثر مبيعاً").
- `"image"`: الصورة اللي بتظهر على كارت المنتج. يُفضّل تكون مربعة
- `"images"`: كل صور المنتج اللي بتظهر في المعرض لما العميل يدوس على المنتج، مثال: `["/images/products/tin-250/1.jpg", "/images/products/tin-250/2.jpg"]`
- حط الصور في فولدر `public/images/products/`
- عشان توقّف منتج مؤقتاً: خلي `"available": false`
- السعر قبل الخصم بيتكتب في `"oldPrice"`، وبيظهر مشطوب جنبه نسبة الخصم. لو مفيش خصم خليه `null`

## مصاريف الشحن
أسعار الشحن متسجلة لكل **منطقة** حسب شيت شركة الشحن، في ملف `data/shipping.json`:
- العميل بيختار المحافظة، وبعدين المنطقة، وجنب كل منطقة سعر الشحن بتاعها.
- لو منطقته مش في القايمة يختار "منطقة تانية" ويكتب اسمها. ساعتها بيتحسب السعر الأساسي للمحافظة، وهو أكتر سعر متكرر فيها، والطلب بيظهرلك في لوحة الإدارة وملف الـ Excel وعليه ⚠️ عشان تتأكد من السعر.
- المحافظات اللي مش في الشيت (زي شمال سيناء) مش بتظهر للعميل.
- السيرفر بيحسب الشحن تاني لما الطلب يوصل، فمحدش يقدر يغيّره من المتصفح.

**لو شركة الشحن بعتتلك شيت أسعار جديد:**
```bash
pip install openpyxl
python3 scripts/import_shipping.py "Price_List.xlsx"
```
السكريبت بيعمل ملف `data/shipping.json` من جديد. مناطق "المدن الجديدة" و"أطراف القاهرة والجيزة" بيوزّعها على القاهرة أو الجيزة. لو الشيت فيه منطقة جديدة في المجموعتين دول، ضيفها في `ZONE_TO_GOV` جوه السكريبت.

## الإعدادات (`.env`)
| المتغير | المعنى |
|---|---|
| `ADMIN_PASSWORD` | باسورد لوحة الإدارة، **لازم تغيّره** |
| `STORE_NAME` | اسم المتجر بالعربي |
| `STORE_NAME_EN` | اسم المتجر بالإنجليزي |
| `STORE_WHATSAPP` | رقم واتساب المتجر بالصيغة الدولية، من غير + ولا مسافات، مثال `971553626134` |
| `SHIPPING_FEE` | مصاريف شحن احتياطية، بتتطبق بس لو ملف `data/shipping.json` مش موجود |
| `FREE_SHIPPING_OVER` | الشحن مجاني لو الطلب فوق المبلغ ده (`0` = مفيش شحن مجاني) |

### تفعيل رسالة التأكيد التلقائية على واتساب (اختياري)
1. اعمل حساب على [Meta for Developers](https://developers.facebook.com/) وضيف منتج **WhatsApp**، واربط رقم المتجر.
2. خد **Access Token** (يُفضّل permanent token من System User) و **Phone Number ID**.
3. اعمل **Message Template** من نوع Utility واستنى لحد ما يتوافق عليه. مثال لنص القالب:
   > أهلاً {{1}}، تم استلام طلبك رقم #{{2}} بإجمالي {{3}}. هنتواصل معاك قريب لتأكيد التوصيل ☕
4. حط القيم في `.env`:
   ```
   WHATSAPP_TOKEN=...
   WHATSAPP_PHONE_NUMBER_ID=...
   WHATSAPP_TEMPLATE_NAME=order_confirmation
   WHATSAPP_TEMPLATE_LANG=ar
   ```
ليه القالب مهم: واتساب مش بيسمح تبعت رسالة نصية عادية لعميل لسه ما كلمكش، فأول رسالة لازم تكون من قالب متوافق عليه.

## الرفع على الإنترنت
الموقع محتاج سيرفر Node.js، فمينفعش يتحط على استضافة ملفات ثابتة بس. ينفع على Render أو Railway أو أي VPS:
- أمر التشغيل: `npm start`
- حط متغيرات `.env` في إعدادات الاستضافة
- **مهم:** الطلبات بتتحفظ في `data/orders.json`، فلازم تستخدم استضافة بمساحة تخزين ثابتة (Persistent Disk / Volume) عشان الطلبات ما تتمسحش لما السيرفر يعمل restart. وصدّر نسخة Excel من الطلبات كل فترة كاحتياطي.
